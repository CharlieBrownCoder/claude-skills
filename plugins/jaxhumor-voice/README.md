# jaxhumor-voice

The Jax Humor voice, built 2026-11-03 (Nate: "give Jax Humor its own voice
plugin"). This repo is its home from that date.

**Version 0.1 is partial, on purpose.** The claude.ai synced skill of this
name was a stub ("Let's create a voice specific to Jax Humor"), but the
`jaxhumor-writing` skill was written against a full voice: nine named joke
patterns, the Conditions Advisory, the newsletter's cold open, a list of Hard
Nos. Those definitions were not found anywhere the build could read. This
version holds only what `jaxhumor-writing` states about the voice, restated
here, and lists the rest under "Not yet written down" instead of inventing
it. Bring the original definitions (or write them) and bump to 1.0.0.

Source: the claude.ai synced `jaxhumor-writing` skill (updated 2026-08-10),
its voice rules, "We vs. you", writing register, joke density, product
families, utility sign-off and edge cases. Nothing in this skill comes from
anywhere else.

Edit it here and bump `version` in `.claude-plugin/plugin.json`. The
claude.ai synced `jaxhumor-voice` stub is stale from this date.
